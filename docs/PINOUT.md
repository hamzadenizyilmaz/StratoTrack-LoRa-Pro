# Pinout

## Working Pinout

### LoRa

| RAK | ESP32-C6 |
|---|---|
| UART2_TX | GPIO0 |
| UART2_RX | GPIO1 |
| 3V3 | 3V3 |
| GND | GND |

### GPS

| GPS | ESP32-C6 |
|---|---|
| TX | GPIO4 |
| RX | optional GPIO5 |
| VCC | 5V |
| GND | GND |

### TFT

| TFT | ESP32-C6 |
|---|---|
| SCK | GPIO6 |
| MOSI | GPIO7 |
| MISO | Not connected |
| CS | GPIO10 |
| DC | GPIO2 |
| RST | GPIO3 |
| BL | 3V3 |
